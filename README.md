# كم النسبة؟ — Show V2

نسخة إعادة بناء لشاشة التلفزيون لتصبح عرضًا واحدًا ذاتي التشغيل بدل واجهة موقع.

## التشغيل
ارفع الملفات كما هي إلى GitHub Pages. افتح `index.html` على شاشة التلفزيون.

## تحكم المضيف أثناء اللعب
- Pause / Resume فقط
- Skip Turn فقط

بقية الانتقالات تلقائية: التخمين → التصويت → التشويق → الكشف → التعليق → النقاط → الدور التالي.

## الصوت
تم تعطيل `speechSynthesis` نهائيًا. اللعبة تبحث عن ملفات MP3 طبيعية داخل `audio/`.
ملف `narrator_script.json` يحتوي النصوص وأسماء الملفات المطلوبة لكل سؤال لتوليد الصوت خارجيًا دفعة واحدة.
